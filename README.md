# Enter-Calc-Out

Учебное приложение на **Windows Forms (C#)** с меню команд **Ввод → Посчитать → Выход**.
Демонстрирует базовые принципы ООП: инкапсуляцию, разделение ответственности и повторное использование логики.

---

## 📋 Возможности

- Главное окно с меню из трёх команд: **Ввод**, **Посчитать**, **Выход**.
- Команда **Посчитать** изначально недоступна и активируется только после успешного ввода данных.
- Диалоговое окно ввода содержит:
  - два поля `TextBox` с метками *Число 1* и *Число 2*;
  - группу из трёх флажков `CheckBox`: **Сумма**, **НОД**, **Произведение**;
  - кнопку подтверждения.
- Расчёт выполняется для любой комбинации отмеченных флажков.
- Результаты выводятся в окне сообщений `MessageBox`.
- Команда **Выход** корректно закрывает приложение.

## 🧠 Архитектура

Проект сознательно разделён на три слоя:

| Слой | Класс | Ответственность |
|---|---|---|
| **Логика** | `Calculator` | Чистые статические методы: `Sum`, `Product`, `Gcd`, `Calculate` |
| **Ввод** | `InputForm` | Диалог, валидация, возврат данных через свойства |
| **Управление** | `Form1` | Меню, хранение введённых данных, вызов логики, вывод результата |

Такой подход даёт:
- **Инкапсуляцию** — данные не «размазаны» по формам, а хранятся в приватных полях.
- **Слабую связанность** — UI ничего не знает о внутренностях алгоритмов.
- **Тестируемость** — `Calculator` легко покрыть unit-тестами без запуска формы.

## 🔍 Как это работает

1. При запуске открывается `Form1` с меню; пункт **«Посчитать»** имеет `Enabled = false`.
2. Выбор **«Ввод»** открывает модальное окно `InputForm`.
3. После корректного ввода чисел и нажатия кнопки данные передаются в `Form1`,
   а пункт **«Посчитать»** становится активным.
4. Выбор **«Посчитать»** вызывает `Calculator.Calculate(...)` и выводит
   строку с результатами выбранных величин через `MessageBox`.
5. Выбор **«Выход»** закрывает главную форму и завершает приложение.

## 🧮 Алгоритмы

- **Сумма:** `a + b`
- **Произведение:** `a * b`
- **НОД:** алгоритм Евклида

```csharp
public static long Gcd(long a, long b)
{
    a = Math.Abs(a);
    b = Math.Abs(b);
    while (b != 0)
    {
        (a, b) = (b, a % b);
    }
    return a;
}
```
